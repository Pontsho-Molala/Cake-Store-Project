# 🍰 Royal Sweet Haven – Cake Store Website

## Project Overview

Royal Sweet Haven is a cake and dessert store website designed to showcase a variety of delicious cakes and sweet treats for different occasions. The website provides visitors with an attractive and user-friendly browsing experience, allowing them to explore products, view prices and learn more about the store.

The project was developed using HTML, CSS and JavaScript to demonstrate foundational front-end web development skills.

## ✨ Features

- **Home Page:** Welcoming landing page introducing the cake store.
- **Cakes Section:** Displays a selection of cakes, including birthday cakes, wedding cakes, chocolate cakes and custom-designed cakes.
- **Desserts Section:** Showcases desserts such as brownies, cupcakes, macaroons, cheesecakes and milk tarts.
- **About Us Section:** Provides information about Royal Sweet Haven and its products.
- **Navigation Bar:** Allows users to navigate between different sections of the website.
- **Search Interface:** Includes an interactive search panel.
- **Shopping Cart Preview:** Displays a shopping cart panel with selected example products.
- **Responsive Layout:** Uses CSS Grid, Flexbox and media queries to adapt the layout to different screen sizes.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structures the website content. |
| CSS3 | Styles the website and creates its layout. |

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Pontsho-Molala/Cake-Store-Project.git
```

### 2. Navigate to the project folder

```bash
cd Cake-Store-Project
```

### 3. Open the website

Open the `index.html` file in your preferred web browser.

Alternatively, use the Live Server extension in Visual Studio Code to preview the website.
